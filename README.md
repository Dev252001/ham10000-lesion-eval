# HAM10000 Skin-Lesion Classification — Leakage-Aware Evaluation

> **Research use only.**
> This code and any results it produces are for academic and educational
> purposes.  They are not validated for clinical use and must not be used
> to inform medical decisions.

---

## Key Findings

**Question.** How much do a naive image-level split and a rigorous lesion-grouped split
differ for 7-class skin-lesion classification on HAM10000?

**Method.** Lesion-grouped, class-stratified 70/15/15 split (seed 42); three models
trained from scratch or fine-tuned; macro-F1 as the primary metric; 95% confidence
intervals from 1 000-replicate cluster bootstrap resampling lesions.

**Result.** EfficientNet-B0 reaches macro-F1 0.648 (95% CI 0.584–0.702) on the
lesion-grouped split.  Under a naive image-level split, 34.8% of test images share a
lesion with training data — image-level split metrics are expected to be inflated but
image-level model runs are not committed to this repository (see the Limitations
section and the manual checklist for how to produce them).

## Evaluation Protocol

- Split: lesion-grouped, class-stratified 70/15/15 (`split_mode="lesion"`, seed 42).
  The manifest CSV and its SHA-256 are recorded with every run.
- Checkpoint selection and early stopping use the validation split only (best
  validation macro-F1; tie-break: lower validation loss).
- The test split is used only once, to evaluate each model's selected checkpoint.
- Class weights are computed from training images only: w\_c = N / (C × n\_c),
  where N = total training images, C = 7 classes, n\_c = training images for class c.
- All models share the data pipeline, loss function, epoch budget (20) and selection
  rule; the learning rate differs (1e-3 for from-scratch, 3e-4 for fine-tuned).
- Primary metric: macro-F1.  Secondary: recall on mel, bcc, akiec.
- Confidence intervals: 95% percentile bootstrap resampling lesion\_id clusters
  (1 000 replicates, seed 0).  Resampling lesions rather than images respects the
  cluster structure of the test set.
- An image-level split is kept only to quantify leakage.

## Grad-CAM Note

Grad-CAM heatmaps highlight image regions with a high class-specific
gradient signal at the chosen convolutional layer.  They are a qualitative
visualisation: a heatmap on the lesion shows the model attended to that region
for that input, but does not establish that the model relies on clinically
meaningful features.  Target layers: ResNet-18 `layer4[-1]`,
EfficientNet-B0 `features[-1]`.

## Limitations

HAM10000 provides `lesion_id` but not patient IDs.  The lesion-grouped split
prevents the same lesion appearing in both train and test, but different lesions
from the same patient may still appear on both sides.  The scale of this
same-patient leakage cannot be quantified from the metadata.

All three models were trained with a single random seed (seed 42).  The bootstrap
CIs reflect test-set sampling variance; they do not capture training variance across
seeds or architecture choices.

The rarest classes have few lesions in the 15% test partition: df has 11 unique
lesions, vasc has 15.  Per-class CIs for those classes are correspondingly wide and
should be interpreted cautiously.

HAM10000 was collected at two acquisition sites.  No external validation set was
used.  Generalisation to images from different clinics, devices or patient
populations is unknown.

Label provenance is mixed: a subset of diagnoses are histopathologically confirmed
while others are based on follow-up examination or expert consensus.  The evaluation
does not separate confirmed from unconfirmed labels.

No systematic hyperparameter search was performed.  Learning rates and the epoch
budget were set once and not tuned against the test set.  The results reflect one
choice of hyperparameters, not a near-optimal configuration.

No image-level model runs are committed, so the lesion-vs-image-level macro-F1
comparison and the corresponding leakage gap CI are not available in this snapshot.
See the manual checklist for instructions to produce them.
